# Bank-ATM

Requires MYSQL workbench for schemas

MYSQL steps
1. Create a schema "bank_login"
2. in the schema create a table "clients"
3. columns cardno varchar(50), username varchar(50), pin varchar(6), balance decimal(10, 2)


ALSO Create a .env file
within the .env file place your jdbc url, user and password.

test.java is for generating values to insert within the database.
